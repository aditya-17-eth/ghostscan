# Design direction

The investigation workspace leads; live status and a legible query field carry the product. No marketing page or fabricated activity.

Palette: ink #07090D, slate #0D1117, elevated slate #121821, boundary #242C38, phosphor #B8FF65, telemetry cyan #68D5FF. Red indicates measured failure; amber indicates explicit direct exposure.

Type: locally available Bahnschrift / Segoe UI for compact product copy; Cascadia Code / Consolas for addresses and measured transport data. No external font requests.

Layout: fixed navigation, compact chain/status bar, left-aligned investigation area beside a transport-design inspector. Real session accounting spans the workspace above a measured request table. Mobile collapses the side navigation and reserves width for the query and results.

The brief explicitly calls for a dark terminal and lime accent. The distinction comes from exact privacy accounting, a persistent route explanation and restrained typography, rather than decorative charts or invented chain activity. Route connections illustrate network design, not measured hops. Different density and surface treatments distinguish input, state results and diagnostics.
